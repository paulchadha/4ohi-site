THE NAME

4. Ohhh. Now you get it.

Four of Hearts became 4OH. Then somebody said it out loud.

We started with card games and a fourth heart. The name stuck. So did the instinct to make software with personality. Today we build original games and useful apps—independently, carefully, and with just enough mischief to keep it interesting.
