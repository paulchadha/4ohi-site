# Canadian-fun copy system

`assets/canadian-copy-v2.js` is the current centralized copy manifest. The active query is `?lang=en-CA-fun`; `assets/canadian-mode.js` applies copy and preserves the query across internal links without cookies or storage.

The manifest contains global/interface copy plus product-specific pools for all ten products, newsroom/empty/error states, and About/footer/support. The voice is dry and specific. It avoids costume stereotypes, invented facts, and jokes inside safety-critical legal meaning.
