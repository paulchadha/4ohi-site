# Palace-family naming and Easter egg

Palace is the canonical public and SEO name. Shed is an ordinary public display choice. The traditional adult alternate name is intentionally private.

## Interaction

1. Open Settings or the table-name panel.
2. Choose Shed.
3. Activate Shed ten times within four seconds.
4. An accessible modal appears with:
   - `NOT SAFE FOR WORK`
   - `The traditional alternate name is “Shithead.”`
   - `Yes, use the traditional name`
   - `No, keep Shed`
5. Confirmation sets only `?game=shithead`; rejection keeps `?game=shed`.

The dialog works with mouse, touch, Enter, and Space. Native `dialog` focus containment and close behavior are used. The selected state is carried only by internal URL parameters. Reloading a fresh URL without the parameter resets to Palace.

The private name must not appear in canonical metadata, Open Graph copy, JSON-LD, sitemap, RSS, help content, or default public navigation. It may appear in factual history source notes and this internal implementation document.
