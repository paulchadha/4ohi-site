## Immersive navigation update — 2026-07-31

The hierarchy remains Four of Hearts Interactive → Games → individual game worlds. The homepage now serves as a spatial world navigator with Palace first, followed by Commander ThumB, Hearts, Spades, and Euchre. Standard company navigation and every deep route remain directly addressable. The homepage Palace table-name control is scoped to the active Palace world and disappears when another world is selected.
