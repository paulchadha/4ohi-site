# Website Information Architecture

## Canonical routes

- `/` or `/index.html` — canonical Palace-led company homepage and product overview.
- `/palace.html` — noindex compatibility redirect to the canonical homepage; preserves query and hash.
- `/palace-play.html` — full three-level website mini-match.
- `/news.html` and `news-*.html` — newsroom and articles.
- `/games.html` — Hearts, Spades, Euchre, and future-table presentation.
- `/hearts-play.html`, `/spades-play.html`, `/euchre-play.html` — local game-specific table moments.
- `/about.html` — family, studio, founder, and philosophy.
- Support, privacy, security, terms, contact, FAQ, and history remain separate supporting routes.

The header logo and Palace navigation share the canonical homepage destination. Back/Forward remains predictable because the legacy route uses replacement navigation. Canonical metadata and the sitemap list only the canonical homepage, not the redirect route.
