# Dynamic Naming and Artwork Architecture

`assets/product-authority.js` is the runtime authority for display name, localized messages, table-name selection, and active artwork. Shared HTML is generated by `scripts/build-site.mjs` with `data-game-token`, `data-game-message`, and `data-brand-message` hooks.

## State

- Default: `Palace`, no `game` query parameter required.
- Family-friendly alternate: `?game=shed`.
- Confirmed traditional alternate: `?game=shithead` after the ten-tap confirmation.
- Locale: `?lang=<locale>`; `en-CA` displays as Canadian.

No state is written to cookies, localStorage, or sessionStorage. Internal links preserve active URL state. Canonical links and public metadata remain Palace.

## Artwork map

- Palace: `palace-hero-{384,640,1024}.webp`
- Shed: `shed-identity-{384,640,1024}.webp`
- Shithead: `shithead-identity-{384,640,1024}.webp`

Images marked `data-game-art`, Palace hero sources, and Palace product backgrounds resolve from this map. Add a new display mode only by extending the allowlist, localized templates, artwork map, confirmation rules, link propagation, and verifier matrix together.
