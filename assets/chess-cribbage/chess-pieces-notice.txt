# Cburnett Staunton chess pieces

The twelve SVG chess pieces in this directory are by **Cburnett**, obtained unchanged from Wikimedia Commons on **23 November 2026**. Original artwork dates shown on the file pages are 27 December 2006. We use the **BSD 3-Clause license** offered on each file page. The pages also offer other licenses; this distribution selects BSD 3-Clause consistently for all twelve files.

Only the local filenames have changed. The SVG bytes, geometry, colors and transparent backgrounds are unmodified. Copyright belongs to the original author. Cburnett and Wikimedia do not endorse Four of Hearts Chess.

Each primary file page was checked for the named author and its BSD license terms before downloading its linked SVG original. Exact upload URLs, byte lengths and SHA-256 checksums are recorded in [sources.json](sources.json). `node scripts/fetch-cburnett-pieces.mjs --verify` checks local files without network access. Run the same command without `--verify` to reproduce the downloads; a changed upstream file fails its pinned checksum before being written.

The earlier original Four of Hearts piece files remain in the parent directory. This versioned set is distributed separately so an asset update does not overwrite them.
